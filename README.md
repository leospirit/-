# 学生成长录模板工坊

基于 Excel/CSV 数据，批量生成统一美化的“日常学习成长录”图片，支持文案占位符与多种配色。

## 快速使用
1. 打开 `index.html`。
2. 上传包含表头的 Excel/CSV（建议包含列：姓名、班级、日期、课堂表现、作业完成度、综合评价等）。
3. 勾选要展示的指标，编写带有 `{列名}` 占位符的文案模板。
4. 选择配色后，可下载当前学生或批量导出全部学生的 PNG 图片。

## 占位符示例
- `{姓名}` `{班级}` `{日期}`
- 任意指标列名，例如 `{课堂表现}` `{作业完成度}` `{探究精神}`

## 依赖
- [SheetJS](https://github.com/SheetJS/sheetjs)（读取 Excel/CSV）
- [html2canvas](https://github.com/niklasvh/html2canvas)（将预览转换为图片）
